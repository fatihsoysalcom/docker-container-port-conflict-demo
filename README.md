# Docker Container Port Conflict Demo

This example demonstrates fundamental Docker container management, including starting and stopping containers. It specifically illustrates how port conflicts arise when multiple containers attempt to use the same host port, and how to resolve them by assigning different host ports.

## Language

`bash`

## How to Run

1. Ensure Docker is installed and running on your system.
2. Save the code as `docker_port_demo.sh`.
3. Run `bash docker_port_demo.sh` in your terminal.
